ECOSYSTEM ROLE MAP

Editable source: ecosystem_map.excalidraw
Exports and previews: ecosystem_map.svg, ecosystem_map.pdf, ecosystem_map.png
Vector drawing data: ecosystem_map_inline.tex

The map contains abstract roles. One institution can perform several roles,
and several institutions can supply the same role. Named examples appear in
the Ecosystem and Summary documents.

Both LaTeX documents embed the map's vector drawing data so that they compile
independently. The editable Excalidraw file is the diagram source of truth.

To update the figure:
1. Edit ecosystem_map.excalidraw in Excalidraw and refresh the exported previews.
2. Update ecosystem_map_inline.tex and the drawing blocks between MAP_MACRO_BEGIN
   and MAP_MACRO_END in both LaTeX documents to match the edited diagram.
3. Recompile both documents and inspect the figure and summary layout.

Labels use Helvetica sans-serif in Excalidraw and standard sans-serif text in
LaTeX. The editable scene retains live text.
