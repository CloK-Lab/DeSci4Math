# DeSci-Market

DeSci-Market is a living record of ideas, mechanisms, ecosystem observations,
and open questions about decentralized science markets. The documentation
will evolve as discussions and practical experience develop.

The current Ecosystem and Summary documents are an initial format for these
notes. The intended direction is a document that can be read and edited on a
website; the repository currently holds its sources, diagrams, and PDF exports.

- [Ecosystem](docs/verification_market_ecosystem.tex) · [PDF](docs/output/pdf/verification_market_ecosystem.pdf)
- [Summary](docs/verification_market_summary.tex) · [PDF](docs/output/pdf/verification_market_summary.pdf)
- [Editable ecosystem map](docs/figures/ecosystem_map.excalidraw)
- [Document files and export instructions](docs/README.md)
- [Overleaf editor](https://www.overleaf.com/project/6ab6baa74349edae79fa13fc)

Update the sources and diagrams as the record develops, then refresh the PDF
exports. Citations and source links are included in the documents. Background
reading collections are maintained locally and are excluded from this repository.
